# 测试说明

本文记录验证入口、覆盖范围和已取得的证据。预期行为见 [产品需求](../docs/产品需求.md)，真实模型的用例结果、语义评审与限制见 [Agent 验证记录](../docs/Agent验证记录.md)。

## 运行

| 命令                                   | 用途                                                                                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `npm test`                             | 运行业务、SQLite、Agent 编排、界面状态和配色回归。                                                                                         |
| `npm run test:desktop`                 | 构建并运行 Electron 桌面回归，使用隔离工作区和本地 Agent 测试传输。                                                                        |
| `npm run test:desktop:today`           | 构建并运行今日安排与重复任务的定向桌面回归。                                                                                               |
| `node tests/review.desktop.mjs`        | 对已构建的应用运行独立桌面审查场景。                                                                                                       |
| `node tests/agent-ui.desktop.mjs`      | 对已构建的应用验证配置恢复、流式、取消、重试和会话交互，使用本地测试传输。                                                                 |
| `node tests/agent-context.desktop.mjs` | 通过模拟模型传输核对一键优化的空状态、仅有预计今天完成任务时首轮发送、草稿保留、接受方案后子任务独立完成，以及调试界面实发请求和会话隔离。 |
| `node tests/pack.smoke.mjs`            | 验证生成的 Windows 目录包启动、Agent IPC、SQLite 和凭据隔离。                                                                              |

桌面脚本通过 `XIXU_DATA_DIR` 使用隔离临时目录，截图及结果写入 Git 忽略的 `test-results/`。受限环境启动 Electron 时可能需要允许本地子进程。

## 工作区与桌面回归

重复任务交付通过 107 项离线用例、格式检查、类型检查、生产构建和六组 Electron 桌面回归。详见 `git show 2d368a0`。

任务调整卡上线前，Agent 重复任务扩展通过 117 项离线用例和六组 Electron 桌面回归，覆盖三种规则、当天操作、旧方案的逐条确认、过期与级联删除范围校验，以及普通和重复动作的事务回滚。当前回归入口为 [Agent 重复任务测试](agent-recurrence.test.ts)、[SDK 工具测试](agent-tools.test.ts)和 [重复任务桌面脚本](recurrence.desktop.mjs)。

自绘窗口、快捷优化和调试面板通过 119 项离线用例、七组桌面回归和 Windows 目录包冒烟测试。桌面脚本验证窗口按钮的键盘与鼠标路径、弹窗中最大化／还原，以及调试展示与模拟传输收到的每个请求体一致。目录包验证调试入口关闭。实际窗口已验证标题栏双击最大化／还原，以及通过 `Alt+Space` 移动和在弹窗中改变窗口大小。鼠标拖动标题栏和边缘调整尺寸未能通过本机自动化复核。优化建议质量留待真实模型复验。

重复任务修复通过 123 项离线测试和七组 Electron 回归。覆盖现有及新建子任务继承、跨日重新开始、独立规则、父规则修改、Agent 拆分和三个视图的完成与恢复。上下文测试核对删除重复模板后，本地仍保留执行记录，模型请求的当前计划和后续工具回执不带旧实例。

重复任务桌面回归还验证撤销提示只包含本次移除，10 秒后收起，重开后保持已移除状态且不重新显示提示。

任务层级与预计完成入口通过 127 项离线测试和七组 Electron 回归。覆盖今日父子去重、三层显示、子任务键盘完成与普通子项移出、列表筛选后的所属任务、待推进分组调序、跨日与已有安排写入保护、预计完成区的键盘安排。

父子完成联动及模板实例隔离通过 132 项离线测试和七组 Electron 回归。新增验证覆盖聚焦顺序、普通任务键盘批选、完成后展开子任务、跨日实例独立、旧实例祖先快照、模板改名后实例方案仍可接受，以及模拟 SDK 补加实例到终答的工具链。

## 真实模型验证

以下命令会调用真实模型并消耗 API 额度。开发实验使用本地 `.env.agent.local`，脱敏结果写入 Git 忽略的 `test-results/`。
真实模型 Agent 用例只在 Agent 变更时按涉及的场景执行。

- `npm run test:agent:live` 串行运行六条真实模型样例。
- `npm run test:agent:journey` 运行 S01 七轮连续对话，末轮同日序列化重读后继续。
- `npm run test:agent:behavior` 验证自然确认、草稿承接、含糊指代、事实纠正和历史查询等场景。用 `XIXU_BEHAVIOR_FILTER` 按逗号分隔的子串选择场景。
- PowerShell 中将 `$env:XIXU_BEHAVIOR_FILTER = 'B09'` 后运行 `npm run test:agent:behavior`，选择重复任务五条场景。
- PowerShell 中设置 `$env:XIXU_BEHAVIOR_FILTER = 'B10'` 后运行 `npm run test:agent:behavior`，核对回复中的系统本地年月日和时分以及空业务动作。
- PowerShell 中设置 `$env:XIXU_BEHAVIOR_FILTER = 'B08,B11'` 后运行 `npm run test:agent:behavior`，检查自然确认、同任务改期和预计完成日期同卡，以及接受后的范围。
- `node tests/agent-real.desktop.mjs` 对已构建的应用发送一轮真实桌面对话，检查 SQLite 保存和重启恢复。

## 验证边界

- 真实用户可用性、不同 Windows 显示缩放、完整视觉状态组合及长时间、大数据量使用待进一步验证。
- 真实模型已覆盖若干授权、事实提炼和连续规划路径。更多措辞、全部场景分支、长期稳定性及真实服务故障与流式取消仍待验证。故障恢复的现有自动化证据主要来自模拟传输。
- 早期原型的逐阶段测试结果可在 Git 查询，例如 `git show 2d368a0:tests/README.md`。
