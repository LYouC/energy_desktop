# 息序 · Energy Desktop

通过对话理解任务、形成背景、拆分目标并协商每日安排的桌面应用。目标是帮助用户更舒服地推进重要的事，同时考虑精力消耗、受挫与恢复。

## 当前状态

产品方向、技术栈和浅色主外观已确认；深色主题是正式应用的必需能力，规范已补齐，HTML 暂未实现深色。

当前仓库只有文档与静态视觉原型。原型仅支持“今日安排 / 所有任务”切换；没有模型调用、任务持久化或可安装桌面应用，也尚未建立 Vue/Electron 工程。

文档按最终决策整理，不要求接手者获得原始聊天记录。产品需求定义行为，设计规范定义外观，技术方案定义实现边界；原型中的日期、数量、对话和任务均为示例，不能据此新增产品规则。

## 下一步

后续开发先建立 Vue/Electron 工程，打通“对话 → 背景与子任务 → 接受方案 → 持久化 → 主窗口展示”的完整流程，再覆盖受阻调整、离散能量状态与明暗主题。技术验证可分步进行，但当前产品范围不缩减为只处理一种困境。

任务图已列入未来范围，本轮不实现。历史原型保留在 `design/archive/`，不作为当前需求依据。版本、模型与打包方式尚未实际验证，不能将本仓库描述为已经可运行的正式应用。
