# 息序 · Energy Desktop

通过对话理解任务、形成背景、拆分目标并协商每日安排的桌面应用。目标是帮助用户更舒服地推进重要的事，同时考虑精力消耗、受挫与恢复。

## 当前状态

产品方向、技术栈和浅色设计稿已确认。仓库目前包含文档和静态设计稿，演示“今日安排”和“所有任务”的切换。Vue/Electron 工程、模型调用和本地保存尚未实现。

下一步用可交互原型验证从描述目标、拆出第一步，到协商并接受今日安排的过程，再根据试用结果细化交互。

## 查看设计稿

在浏览器打开 [浅色设计稿](design/index.html) 即可查看，样式文件随设计稿保存在同一目录。
