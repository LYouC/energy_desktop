# 设计规范

`design/index.html` 与 `design/style.css` 是已确认的浅色视觉参考。本文补充深色主题及实际界面的检查项。产品行为见 [产品需求](产品需求.md)。

## 1. 视觉方向与布局

暂用名称“息序”。保持温暖、安静、简洁的个人工作台：暖白、低饱和绿色、细线、适度留白、极轻阴影。信息层级用于帮助行动，避免营销式首屏、大型装饰、密集仪表盘和大量激励标语。

桌面三栏：左侧约 228px 为纯导航；中间为弹性主工作区；右侧约 372px 为 Agent 对话。宽屏可略增左右宽度及留白；对话面板始终保留在右侧，窗口收窄时各栏按宽度收敛；不能把任务列表移回左侧或造成横向溢出。

左右两栏均可折叠：左侧收起后保留约 64px 图标栏，导航、新建与个人空间入口以图标加提示呈现；右侧收起后保留约 48px 竖条，点击可展开。对话栏左缘提供拖拽调宽，向左拖变宽、向右拖变窄，范围 300–560px，且不挤占主工作区最小宽度；支持键盘方向键微调与双击恢复默认。折叠状态与自定义宽度保存在本机，随窗口尺寸自动收敛，不造成横向溢出。

窗口收窄时三栏同时收敛：对话面板宽度随可用空间自动收窄（应用最小窗口下约 280px），仍可收起为 48px 竖条并随时展开；不将对话移到主工作区下方，也不隐藏。收起与展开按钮的箭头指示面板动向：收起对话向左收拢，展开对话向右展开。

窗口顶端使用与导航栏同色的自绘标题栏，右上角放置最小化、最大化／还原和关闭按钮。空白处保留拖动与双击，控件须有悬停、键盘焦点和可访问名称，关闭按钮的悬停样式使用主题危险色。弹窗保留工作区键盘焦点，Windows 可用 `Alt+Space` 访问系统窗口菜单。

- **导航**：视图入口在上，个人空间与设置位于底部。入口范围见产品需求 R09。
- **今日安排**置顶当前聚焦组，其余事项按规划顺序显示。队列有待完成的重复轮次时，当前聚焦项也可参与调序。「重复」标签紧靠名称，管理模式和已完成列表沿用同一位置。与名称不同的本次范围显示在标题下方。休息提示保持轻量。
- **所有任务**使用紧凑列表，展示名称、已标注的重要性及必要的安排信息。每个重复任务占一项，「重复」标签紧跟名称，频率作为辅文，应做日期放在行尾。逾期只将日期着红。行首勾选框负责当前轮的完成和撤销，未来轮次仅显示日期。已停止的重复任务用静态暂停图标取代完成框，今日保留的完成卡片沿用此图标。行尾「完成 N 次」打开日期记录。类型、重要性和完成状态筛选与名称搜索并列，窄窗口允许换行。切换视图时同步导航和顶部路径。
- **今日子任务**缩进放在所属任务卡片内，行间用主题细线分隔。一次性任务和可操作的重复轮次使用一致的完成框，名称打开详情，行尾菜单提供聚焦、同级调序与移出。已完成组默认折叠子任务，提供展开入口。管理模式可选择各已安排事项。
- **所有任务的层级**用缩进和左侧细线表示。筛选后单独显示的子任务附所属任务名称。
- **预计今天完成**在今日队列后单列，待办行提供完成框和安排入口。「今日已完成」位于待办下方，默认折叠，包含已完成的今日安排和预计日期为今天的已完成任务。展开后可查看和恢复。
- **已完成**视图分开展示整体完成的任务，以及应做日期为今天且已完成的重复轮次。
- 「所有任务」在符合条件的任务行右侧提供「安排到今天」。它和开启任务详情的区域分别可用键盘操作，入队后状态显示为「今日」。窄窗口允许操作换行。
- 跳过今天后，在今日队列上方短暂显示本次移除数量及撤销入口。提示随 10 秒超时、成功撤销或离开页面收起，重开应用时不重现。
- **对话**：用不同样式呈现用户消息、Agent 说明和规划方案。将下一步提示放在相关回复或方案内，快捷输入和编辑框放在对话底部。

任务背景按需查看。能量用状态名称和短说明，不用分值或进度条。任务调整卡列出建议内容和理由，待处理时显示一组接受和拒绝按钮。处理成功后显示「已接受」或「已拒绝」，执行失败时收起按钮并显示原因。

任务与子任务共用同一编辑器，显示名称、重要性、重复设置、说明和所属任务。一次性任务显示整体状态与预计起止日期，保存只修改任务属性。重复规则按类型显示星期或日期范围，并预览首次或下一次安排，今日卡片打开同一任务详情。子任务列表提供打开与添加入口。

系统无衬线字体（Segoe UI / 苹方 / 微软雅黑）；标题约 30px，重点任务约 15px，其他正文约 13px，辅文可按实际显示比例调整。卡片圆角 11–13px、按钮约 6–8px，线性图标约 16–18px。不机械复制静态稿中的小字号和浅文字，正式实现应优先保证可读性。

## 2. 主题切换要求

浅色与深色适用同一布局和信息层级。主题选项、初始值和偏好保存见 [产品需求](产品需求.md) 第 6 节。

在左下个人空间或设置区域提供可发现的主题入口。三栏、任务、对话、输入、菜单、提示、滚动条、选择态、禁用态和键盘焦点全部适配。首次渲染前确定生效主题，避免先闪浅色再进入深色。

深色延续柔和的森林灰绿，不使用整页反色滤镜或纯黑底配纯白字。用不同明度的背景建立表面层次，适度降低阴影并强化边界；不通过发光和高饱和色制造强调。

## 3. 语义配色

下表是正式实现的双主题起点；浅色延续原型，少数文字色已适当加深。使用语义变量统一管理，不把这些颜色散落硬编码在组件内。可映射到 Tailwind 与 shadcn-vue 的主题变量；变量命名可调整，语义要保持。

| 语义           | 浅色      | 深色      |
| -------------- | --------- | --------- |
| 应用底色       | `#FCFBF8` | `#171C17` |
| 导航底色       | `#F3F3ED` | `#1C231D` |
| 卡片/浮层      | `#FFFEFA` | `#222A22` |
| 对话区底色     | `#F8F9F4` | `#1B221D` |
| 主文字         | `#303B30` | `#E5EBDD` |
| 次级文字       | `#5F6C5B` | `#BAC6AF` |
| 可读辅助文字   | `#606D56` | `#A1AF94` |
| 分隔/边界      | `#E5E8DD` | `#384334` |
| 强调文字/图标  | `#536A46` | `#B2C798` |
| 选中背景       | `#E7EDDF` | `#303F2A` |
| 能量等柔和区域 | `#F1F5EA` | `#283323` |
| 主按钮底色     | `#5D7451` | `#A9BF8D` |
| 主按钮文字     | `#FFFEFA` | `#192115` |
| 截止提示       | `#80643E` | `#D1B58C` |
| 控件边界/焦点  | `#6A765F` | `#8FA379` |

深色按钮使用浅绿底和深色字，与浅色的深绿按钮成对设计。选中与柔和区域的文字使用主文字或强调文字，不直接套用只在基础底色上验证过的辅助文字。日期、次要标签、占位符和禁用态需分别判断，不能把所有辅助文字无限降低透明度。能量偏低不等于错误，不将疲惫状态渲染成警报红。

常规正文对比度至少 4.5:1，大字号至少 3:1。重要边界、图标和焦点相对于邻接背景至少 3:1。按实际组件叠放、背景与交互状态检查对比度。

## 4. 视觉验收

正式应用至少验证两种主题下的今日安排、所有任务、已完成、任务详情与背景、规划方案、能量选择、模型设置及错误和空状态。检查弹层背景是否随主题更新，输入与选中态是否可读，键盘焦点是否明确。用不同窗口宽度和显示缩放复核。

实际桌面与对比度覆盖见 [测试说明](../tests/README.md#工作区与桌面回归)。
