# 设计规范

更新：2026-11-15。用户已基本满意当前主外观。`design/index.html` 与 `design/style.css` 是浅色视觉参考；深色主题规范在本文补充，HTML 当前未实现深色。产品行为以 [产品需求](产品需求.md) 为准。

## 1. 视觉方向与布局

暂用名称“息序”。保持温暖、安静、简洁的个人工作台：暖白、低饱和绿色、细线、适度留白、极轻阴影。信息层级用于帮助行动，避免营销式首屏、大型装饰、密集仪表盘和大量激励标语。

桌面三栏：左侧约 228px 为纯导航；中间为弹性主工作区；右侧约 372px 为 Agent 对话。宽屏可略增左右宽度及留白，小窗口将对话排在主工作区下方；不能把任务列表移回左侧或造成横向溢出。

- **导航**：今日安排 / 所有任务 / 已完成，个人空间与设置位于底部。无外部来源、收集箱、“接下来”入口。具体任务不在左侧展示。
- **今日安排**：日期、标题、离散能量状态、重点任务完整卡片与子任务、休息间隙、其他今日任务的开放式列表行。通过层级突出当前行动，减少同等重量卡片堆叠。
- **所有任务**：替换主工作区内容，简洁单行列表呈现名称、完成标记及必要的简短安排信息。不默认展开背景或子任务；切换同步导航与顶部路径。
- **对话**：保留用户消息、Agent 说明、规划方案、清晰的接受状态、下一步提示、快捷输入和编辑框。导航切换保留对话。
- **已完成**：用于查看完成记录；HTML 中只是入口，正式实现应符合真实任务状态。

任务背景按需查看，今日阶段与整体完成分开表达。能量用状态名称和短说明，不用分值或进度条。休息作为节奏提示，避免强制奖励感。规划方案必须区分待接受、部分接受、已接受，不能只靠颜色传达状态。

系统无衬线字体（Segoe UI / 苹方 / 微软雅黑）；标题约 30px，重点任务约 15px，其他正文约 13px，辅文可按实际显示比例调整。卡片圆角 11–13px、按钮约 6–8px，线性图标约 16–18px。不机械复制静态稿中的小字号和浅文字，正式实现应优先保证可读性。

## 2. 主题切换要求

必须支持浅色和深色。工程默认增加“跟随系统”，初始跟随系统；用户手动选择优先于系统，保存该偏好并在下次启动恢复。

在左下个人空间或设置区域提供可发现的主题入口，允许选择浅色 / 深色 / 跟随系统。三栏、任务、对话、输入、菜单、提示、滚动条、选择态、禁用态和键盘焦点全部适配。仅“跟随系统”时响应系统变更；首次渲染前确定生效主题，避免先闪浅色再进入深色。

主题切换只更新外观，不调用模型、不重新分析、不改任务、能量或方案，也不清空输入草稿、对话与当前视图。

深色延续柔和的森林灰绿，不使用整页反色滤镜或纯黑底配纯白字。用不同明度的背景建立表面层次，适度降低阴影并强化边界；不通过发光和高饱和色制造强调。

## 3. 语义配色

下表是正式实现的双主题起点；浅色延续原型，少数文字色已适当加深。使用语义变量统一管理，不把这些颜色散落硬编码在组件内。可映射到 Tailwind 与 shadcn-vue 的主题变量；变量命名可调整，语义要保持。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 应用底色 | `#FCFBF8` | `#171C17` |
| 导航底色 | `#F3F3ED` | `#1C231D` |
| 卡片/浮层 | `#FFFEFA` | `#222A22` |
| 对话区底色 | `#F8F9F4` | `#1B221D` |
| 主文字 | `#303B30` | `#E5EBDD` |
| 次级文字 | `#626F5E` | `#BAC6AF` |
| 可读辅助文字 | `#6A765F` | `#98A68B` |
| 分隔/边界 | `#E5E8DD` | `#384334` |
| 强调文字/图标 | `#536A46` | `#B2C798` |
| 选中背景 | `#E7EDDF` | `#303F2A` |
| 能量等柔和区域 | `#F1F5EA` | `#283323` |
| 主按钮底色 | `#5D7451` | `#A9BF8D` |
| 主按钮文字 | `#FFFEFA` | `#192115` |
| 截止提示 | `#80643E` | `#D1B58C` |
| 控件边界/焦点 | `#6A765F` | `#8FA379` |

深色按钮使用浅绿底和深色字，与浅色的深绿按钮成对设计。选中与柔和区域的文字使用主文字或强调文字，不直接套用只在基础底色上验证过的辅助文字。日期、次要标签、占位符和禁用态需分别判断，不能把所有辅助文字无限降低透明度。能量偏低不等于错误，不将疲惫状态渲染成警报红。

常规正文对比度至少 4.5:1，大字号至少 3:1；重要边界、图标和焦点相对于邻接背景至少 3:1，细装饰分隔线不承担唯一识别作用。上述深色主文字对底色约 14.21:1、次级文字对卡片约 8.29:1、辅助文字对对话底约 6.31:1、按钮文字对按钮底约 8.29:1；这些是配色计算结果，不代替最终组件组合与视觉验收。

## 4. 原型与后续验收

当前 HTML 只演示两种主视图切换，任务、数量、日期、进度与对话均为示例。没有实现模型、数据库、设置、能量修改或主题切换，不把按钮外观等同于功能完成。

正式应用至少验证两种主题下的今日安排、所有任务、已完成、任务详情/背景、规划方案、能量选择、模型设置及错误/空状态；检查弹层不残留浅底、输入与选中态可读、键盘焦点明确，并在不同窗口宽度和显示缩放下复核。

未来任务图读取同一今日计划，但本轮不设计图形、不放置占据主要位置的未实现入口。`design/archive/` 是历史对比稿，不参与当前设计验收。
