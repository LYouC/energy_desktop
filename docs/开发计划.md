### 今日任务和重复实例修复

| 预期效果 | 问题表现 | 修复与验证 |
| --- | --- | --- |
| 模板负责生成，实例记录本次结果 | 只有保存了显式规则的任务才自行生成。修改一次实例还会更新模板版本，已生成实例的分组跟随模板现有的父子关系。 | 子任务按有效规则结算。实例保存生成时的名称与归属，并维护自己的版本。测试覆盖同日模板改名、重挂、实例编辑、跳过恢复与次日生成。 |
| 今日各入口使用相同的阶段完成状态 | 「今日安排」读取阶段状态，「已完成」以前只读取整体任务状态。子任务曾同时显示在父卡和待推进队列。 | 从同一份当日安排派生列表和分组，整体完成单列。父项完成在一次写入中覆盖当天仍有安排的后代，完成组默认折叠。桌面验证完成、展开、恢复和跨页状态同步。 |
| 计划、日期提示和短时反馈各有用途 | 预计今天完成的任务在今日页面缺席，旧撤销提示随存储记录在重开时再次出现。 | 预计完成单列，显式点击安排才写入，写入时重新核对资格。撤销提示只显示最近一批移除，移除结果独立保存。桌面验证重启、撤销与实际安排。 |
| Agent 能分别处理模板和指定实例 | 已删除模板保留的本地实例曾被当作当前计划发送。规则自动生成之外，缺少补加当天一次的入口。 | 当前计划只读取现存任务。工具分开表达模板与当天实例，支持补加、改范围、完成、移除和恢复。完成方案核对其原有的当天子项范围。模拟 SDK 验证工具执行与回执。 |

缺陷集中出现的原因有三类。首先，模板与实例共享任务 ID，这本来用于追踪来源，后来也被当成同一份写入状态。其次，各页面分别从整体任务、阶段安排和跳过记录推导界面，缺少一组统一的跨页面规则。最后，早期测试多验证单条规则和单次操作，未覆盖改模板后编辑实例、跨视图、重开、过期方案等组合路径。以上为根据代码和回归用例得到的判断。

此阶段通过 132 项离线测试和七组 Electron 回归。Agent 工具执行与回执通过模拟 SDK 验证，真实模型的自然语言理解仍待复验。 [验证入口](../tests/README.md)
