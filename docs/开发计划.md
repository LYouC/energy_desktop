## 后续事项

### 所有任务按完成状态筛选

在现有筛选栏加入「全部状态」「已完成」「未完成」，默认全部状态。验收时核对与任务类型、重要性和名称搜索联用后的列表与计数。一次性任务按整体完成状态判断。

### 明确逾期任务处理规则

先确定逾期判定、展示、重新安排和 Agent 候选规则，再补齐产品验收条件。 [逾期任务](待确认需求.md#逾期任务)

### Agent 效果优化

核实已完成事项出现在取消建议中的反馈。确认调整卡点击与执行结果如何进入下一轮对话，再确定实现与验收范围。 [取消已完成安排的反馈](待确认需求.md#bugagent-建议取消已完成任务的安排) · [调整卡的点击结果](待确认需求.md#agent-感知调整卡的点击结果)

### 持续验证

真实用户试用、Windows 鼠标拖动与缩放、长时间运行和较大工作区待验证。Agent 优先复验重复任务、近期安排与多轮协商。 [桌面验证边界](../tests/README.md#验证边界) · [Agent 待复验项](Agent验证记录.md#覆盖范围与后续验证)
