产品行为见 [产品需求](产品需求.md)，架构与关键决策见 [技术方案](技术方案.md)。

## 当前目标

**交付重复任务的桌面操作。** 工作台支持设置规则、处理今日实例和查看执行记录。Agent 可读取规则与当日实例。

本阶段已通过自动化验收，覆盖本地日期结算、当天调整与撤销，以及删除模板后仍可查看历史。 [重复任务验证](../tests/README.md#工作区与桌面回归)

## 下一步

### Agent 操作重复任务

复用现有 Agent 工具循环，接入模板的创建、规则修改与删除，以及当天实例的范围修改、完成、移除与撤销。

完成条件：

- 能明确目标和本地日期，区分单次操作与改变后续规则。按现有规则处理明确授权和待接受建议。
- 通过跨日结算、删除模板后保留历史、过期方案及混合操作原子性的验证。
- 记录桌面和真实模型实际覆盖的场景，以及仍待验证的表达和边界。

### 持续验证

待补充真实用户试用、Windows 显示缩放、长时间运行和较大工作区的验证。复验真实模型时，核对授权范围、事实提炼、工具结果与回复是否一致，以及故障和取消后的恢复结果。 [测试说明](../tests/README.md#验证边界) · [Agent 验证记录](Agent验证记录.md)

阶段验收、范围调整或出现阻塞时，更新对应条目和证据链接。开始下一阶段时更新当前目标。
