## 当前目标

### 工作台窗口与 Agent 快捷操作

- 窗口使用自绘的最小化、最大化／还原和关闭控件，支持浅色与深色主题。可通过标题栏拖动或双击窗口，并使用窗口边缘调整尺寸。
- 「一键优化」发送一条可见的对话消息，由 Agent 根据今天待推进的安排提出方案，用户接受后执行。空会话可直接发起首轮。没有待推进安排时在本地提示，保留当前草稿。
- 开发版「调试上下文」显示当前会话已捕获的实际模型请求，默认看到最近一轮的最后一次请求，可切换轮次及同轮的工具步骤和终答请求。

本阶段通过 119 项离线测试、七组 Electron 桌面回归和 Windows 目录包冒烟测试。实际窗口已验证标题栏双击、系统菜单移动与缩放；鼠标拖动和真实模型建议质量待复验。 [产品需求](产品需求.md) · [测试说明](../tests/README.md)

## 上一阶段

### Agent 操作重复任务

复用现有 Agent 工具循环，接入模板的创建、规则修改与删除，以及当天实例的范围修改、完成、移除与撤销。

完成条件：

- 能明确目标和本地日期，区分单次操作与改变后续规则。按现有规则处理明确授权和待接受建议。
- 通过跨日结算、删除模板后保留历史、过期方案及混合操作原子性的验证。
- 记录桌面和真实模型实际覆盖的场景，以及仍待验证的表达和边界。

工作台和 Agent 的重复任务操作已通过离线与 Electron 回归，覆盖日期结算、历史保留、方案部分接受和事务回滚。真实模型 B09 已加入场景套件，本地模型配置缺失，语义验收待补。 [重复任务验证](../tests/README.md#工作区与桌面回归) · [Agent 验证记录](Agent验证记录.md)
