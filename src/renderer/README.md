# 工作台界面

| 文件或目录                                     | 内容                                                                              |
| ---------------------------------------------- | --------------------------------------------------------------------------------- |
| `index.html`、`main.ts`、`style.css`           | Vite 的 HTML 和 Vue 入口，主题首屏初始化及全局样式。                              |
| `App.vue`、`stores/workspace.ts`               | 工作台三栏、导航、今日安排与任务列表组合，工作区数据加载及命令队列。              |
| `components/`                                  | 任务编辑、任务卡片、管理多选、对话、历史和模型设置。通用按钮在 `components/ui/`。 |
| `composables/taskSelection.ts`、`lib/utils.ts` | 管理模式选择规则与通用 CSS 类合并。                                               |
| `env.d.ts`                                     | 声明 preload 提供的 `window.desktop` 类型。                                       |

## 工作台与主题

`WindowTitleBar.vue` 使用主题变量绘制窗口控件，通过 [桌面桥接](../desktop/README.md)操作当前窗口，标题栏空白处沿用 Electron 的拖动区域。

`TaskEditor.vue` 统一编辑任务与子任务的属性。一次性任务可设置整体状态与预计起止日期，选择父任务时排除当前任务及其后代。

「所有任务」把「重复」放在任务名称右侧，另显示频率、下次安排和已标注的重要性。任务类型、等级筛选和名称搜索共同决定可见任务及管理模式的选择范围，切换筛选后只保留可见选中项。

符合资格的任务行右侧提供「安排到今天」，点击后留在列表并更新行内状态。行内操作和打开详情是两个独立按钮，键盘安排后焦点回到该行。

重复从 `TaskEditor.vue` 设置。每天、每周自选星期和指定起止日期共用一个入口，显示首次或下一次安排。今日队列在任务名称旁显示「重复」或「临时安排」。重复实例和手动临时安排的本次范围由 `OccurrenceEditor.vue` 编辑，与名称相同时在卡片中合并显示。从今天移除时，`App.vue` 为最近一批操作短暂显示撤销提示。移除结果保存到工作区，提示只存在于当前页面。批量管理分别提供移除重复实例、移出临时安排和永久删除普通任务。删除重复模板从任务列表发起，已有实例仍可完成、调序、移除。删除会影响重复子任务时，确认前显示它们的名称。

切换本地日期时重新加载工作区，更新今日安排。

`App.vue` 持有侧栏折叠、对话折叠与对话宽度状态，经 localStorage 保存。`ChatPanel.vue` 提供对话栏折叠和拖拽调宽入口。UI 使用 shadcn-vue 源码组件，Button 组合 Reka Primitive、CVA 与 cn，弹层使用 Reka Dialog 管理焦点。

列表页与今日安排共用“管理”多选：`ManageToggle.vue` 提供统一入口，`ManageBar.vue` 展示已选数量、全选与删除入口，`composables/taskSelection.ts` 负责选择状态、可见项收敛与父子删除去重。删除前用 `Modal` 确认，确认后逐个提交 `deleteTask`；中途失败会保留剩余目标并显示原因。管理模式下任务卡切换为紧凑选择行，退出或切换视图会清空选择。该功能以 `npm test` 与 `npm run build` 验证。

Pinia 的 `workspace` 持有业务数据的界面副本，所有写入串行调用受控 IPC。写入失败显示错误并刷新，用户编辑表单保留。SQLite 是持久化来源。

今日安排将未完成的聚焦组置顶，管理模式将实际聚焦项置顶，预计完成区排在计划之后。显式切换聚焦不改计划顺序，打开详情只更新右侧对话上下文。含有待执行重复实例时，可调序所有待推进组，包括当前聚焦组；仅有普通任务时，从其余待推进组调序。移动整组保留组内顺序。已安排和预计今天完成的普通任务共用整体完成命令，父项联动完成各层一次性子任务。重复实例仍记录本次结果。整组完成后默认折叠子任务，恢复只改被选中的项。

「已完成」展示整体完成的任务和当天完成的重复实例及临时安排。「所有任务」按一次性任务的整体状态和重复任务当天的安排显示进度。任务编辑器显示子任务继承关系与当日进度，重复筛选和临时安排按工作区计算的有效规则显示。

「今日已完成」同时读取当天完成的安排，以及预计日期为今天、已整体完成的未安排任务。恢复后者会回到「预计今天完成」。

`lib/taskGroups.ts` 计算今日分组和任务列表层级。`TaskCard.vue` 把子任务放入最近的已安排上级卡片，菜单提供聚焦、同级调序与移出。待推进组按组内第一条未完成安排排序。预计完成区通过「安排到今天」提交写入，领域层核对提交时的资格。

主题缓存只用于首次绘制，SQLite 保存用户正式选择。系统主题事件只在跟随系统模式改变外观。默认空工作区，验证数据使用隔离临时目录。

`npm run test:desktop` 实际启动 Electron，覆盖主要交互和重启恢复。已构建应用可直接运行 `node tests/task-fields.desktop.mjs` 验证任务编辑。验证范围见 [测试说明](../../tests/README.md)。

## 对话与模型设置

对话按任务调整卡展示建议理由、日期与字段变化。普通任务移期显示原日期和新日期，接受后按卡片上的日期执行。未处理的卡片显示一组接受与拒绝按钮。处理结果显示「已接受」或「已拒绝」。接受失败时收起按钮，在原卡片上显示失败原因。

`ChatPanel.vue` 管理流式预览、取消和失败后的本轮重试。重试复用原请求并清空失败尝试的流式预览。`ChatHistory.vue` 管理分页与删除确认，使用[会话领域规则](../domain/conversations.ts)统一排序。`ModelSettings.vue` 展示公开模型配置与凭据状态，使用过的 Key 从输入状态清空。

上下文预览复用 [Agent 上下文构建](../agent/context.ts)。发送消息、提交任务和保存模型设置都走[桌面桥接](../desktop/README.md)。`tests/agent-ui.desktop.mjs` 使用本地测试传输验证对话交互。

对话底部「一键优化」使用正常发送流程，保留已有草稿。已安排与预计今天完成两区任一有待处理事项即可发起，两区都没有时显示提示。开发版的 `AgentContextDebug.vue` 展示当前会话实发的模型请求，默认选中最近一轮的末次请求，可切换到该轮的工具步骤或更早轮次。
